# Liver-Cancer-Prediction
Liver Cancer Prediction
Project Description

This project is a Machine Learning based Liver Cancer Prediction System developed using Python, Flask, and Scikit-learn. The application predicts whether a patient is likely to have liver disease based on medical parameters such as age, bilirubin levels, albumin, proteins, and other clinical attributes. The project provides a user-friendly web interface where users can enter medical details and receive prediction results instantly.

The system uses various machine learning algorithms including Logistic Regression, Decision Tree, Random Forest, and Support Vector Machine (SVM) for classification and prediction. Data preprocessing techniques such as handling missing values, encoding categorical data, and balancing the dataset using SMOTETomek were applied to improve model performance.

The frontend of the application was developed using HTML and CSS, while Flask was used as the backend framework to integrate the trained machine learning model with the web application. The trained model was saved using Pickle for real-time predictions.
