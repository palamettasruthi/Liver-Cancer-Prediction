# Liver-Cancer-Prediction
 Liver Cancer Prediction

This project is a Machine Learning based Liver Cancer Prediction System developed using Python, Flask, and Scikit-learn. The application predicts whether a patient is likely to have liver disease based on medical parameters such as age, bilirubin levels, albumin, proteins, and other clinical features.

The project uses machine learning algorithms including Logistic Regression, Decision Tree, Random Forest, and Support Vector Machine (SVM) for prediction and classification. Data preprocessing techniques such as handling missing values, encoding categorical data, and balancing the dataset were applied to improve model accuracy.

The frontend was developed using HTML and CSS, while Flask was used as the backend framework to integrate the trained machine learning model with the web application.

 Technologies Used
Python | Flask | Scikit-learn | Pandas | NumPy | Matplotlib | Seaborn | HTML | CSS

 Features
- Real-time liver disease prediction
- User-friendly web interface
- Data visualization and analysis
- Multiple machine learning algorithms

This project demonstrates the practical implementation of machine learning in healthcare applications for early liver disease prediction.
